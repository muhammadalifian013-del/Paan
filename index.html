📲 Instal Aplikasi ke HP & Desktop

Jika tombol hijau "Instal Aplikasi" di bagian atas muncul, langsung klik tombol tersebut untuk memasang aplikasi dalam 1 ketukan.

1. Cara Pasang di HP Android (Chrome / POCO):

Ketuk ikon titik tiga (⋮) di pojok kanan atas browser → pilih Tambahkan ke layar utama (Add to Home screen) → ketuk Instal.

2. Cara Pasang di Laptop Windows (Chrome / Edge):

Klik ikon Instal Aplikasi (layar dengan panah) di sisi kanan bilah alamat browser, atau klik ⋮ → Simpan dan bagikan → Instal halaman sebagai aplikasi.

3. Jalankan Langsung dari Paket Installer ZIP:

Ekstrak file ZIP installer, lalu klik ganda Jalankan_Aplikasi_Windows.bat di laptop Windows untuk otomatis membuka server lokal dan memunculkan tombol instalasi resmi.
